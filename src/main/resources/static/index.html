How SkillProof Works

A transparent four-step workflow connecting practical effort with cryptographic proof.

1. Choose a Challenge

Browse challenges filtered by prerequisite readiness. Challenges range from CLI utilities to normalized database architectures and containerized deployments.

2. Submit Real Code

Submit your working GitHub repository, deployed preview URL, and technical design notes. No multiple-choice trivia — only actual software.

3. Mentor Rubric Review

Experienced mentors grade your implementation against a clear, multi-point rubric covering architecture, testing, error safety, and code quality.

4. Verified Credentials

Approved submissions issue an indelible verification badge code. Share your public profile with prospective hiring managers and teams.

Frequently Asked Questions

Everything you need to know about verification and peer review.

What makes a skill "Verified" on SkillProof?
A skill is only marked verified after a student successfully submits authentic practical project evidence meeting all requirements, evaluated and approved by an authorized mentor with rubric scoring.
How does Email OTP authentication protect my account?
Authentication generates cryptographically secure 6-digit codes on the backend that expire in 5 minutes. Only secure hashes are saved in the database, with rate limits, attempt thresholds, and lockout protection.
How does the prerequisite recommendation engine work?
SkillProof models skills and challenges as a directed acyclic graph (DAG). The backend evaluates completed competencies, detects circular loops, and produces explainable suggestions for your next learning milestone.
Can I keep my profile private?
Yes. Every user has granular privacy controls to hide public profiles, exclude their score from the leaderboard, or keep mentor reviews private.
